# 📚 BookSwipe

**Tinder for Books** — Swipe right to like, swipe left to skip. Discover your next read.

## Features
- 📖 Swipe through books with a Tinder-style UI
- 🏷️ Filter by categories (Romance, Sci-Fi, Thriller, etc.)
- ❤️ Save liked books to your personal reading list
- 📋 Book details: description, page count, reviews, cover image
- 📱 Cross-platform: Android, iOS, Web, Desktop

## Tech Stack
- **Frontend:** Flutter (Dart)
- **Backend:** Python FastAPI
- **Database:** PostgreSQL
- **Book Data:** Google Books API
- **CI/CD:** GitHub Actions
